# 需求概要

**目的**: 考勤线上化 (员工本人电子签核) 加入职资料线上推送 (签收有记录).
系统是凭证载体, 不做考勤计算, 指标由业务导入.

**范围**: PC 端加企微, 企微本期只做消息推送, 见 [ADR-011](DECISIONS.md).

## 关键需求

| 领域 | 需求 | 状态 |
|---|---|---|
| 考勤处罚 | K1 签收承诺加手写签名 | 已做 |
| | K2 签字过程可回溯 | 未做 |
| | K3 指标只展示不计算 | 已做 |
| | K4 最新期和历史期分开 | 已做 |
| | K5 处罚跟着考勤走 | 已做 |
| | K6 催办有精确对象 | 已做, 文案待确认 |
| 通知确认 | K7 入职资料下发加签收 | 未做 |

核心是 K1, K2, K3. 模型见 [DATA-SCOPE.md](DATA-SCOPE.md).

其余 (登录, 权限, 文案, 兼容性, 部门/角色/用户维护) 按常规实现.
量: 导入 5000 条, 通知 5000 人, 上传 180 秒内.
